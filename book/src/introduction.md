# Introduction

Presolve simplifies an optimization problem before it reaches the solver. It can remove redundant constraints, substitute variables, tighten bounds, and identify infeasibility or unboundedness. Postsolve maps solutions and certificates back to the original coordinates.

Start with [Problem formulation](./problem_formulation.md) for notation and input conventions. [Settings](./settings.md) explains how to adjust behavior, while [Rule scheduling](./scheduling.md) describes the execution order and stopping policy. The rule pages develop the reductions through examples and mathematical arguments.
